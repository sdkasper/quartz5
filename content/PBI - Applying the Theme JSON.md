# Applying the Theme JSON

To apply your custom Power BI Theme JSON file to a report or dashboard:

1. Open the Power BI Desktop application.
2. Load your report or create a new one.
3. Go to the "View" tab and select "Themes."
   ![[Open Theme Selector in PBI Desktop.webp]]
4. Click "Browse for Themes" and select your custom Theme JSON file.
   ![[Browse for Theme in PBI Desktop.webp]]
5. The theme will be applied to your report, and you can preview the changes.
