# Table Accent
The `"tableAccent"` property is used to define a specific color that accentuates or highlights elements within tables, such as headers, selected rows, or specific data points.

It helps to make table-related elements stand out and draw attention to critical information, enhancing the overall usability and clarity of your Power BI reports and dashboards.

## Syntax
```JSON
{
	"name": "LeanProductivity",
	"tableAccent": "#25D0F7"
}
```
